# Ecommerce 

Ядро для интернет-магазина на Python с использованием ООП.

## Реализованный функционал

### Класс Product
- **name**: Название товара (строка)
- **description**: Описание товара (строка)
- **price**: Цена товара (число с плавающей точкой)
- **quantity**: Количество в наличии (целое число)

### Класс Category
- **name**: Название категории (строка)
- **description**: Описание категории (строка)
- **products**: Список товаров в категории (список объектов Product)
- **category_count**: Счетчик всех категорий (атрибут класса)
- **product_count**: Счетчик всех товаров (атрибут класса)

### Запуск основной программы
 
python main.py
